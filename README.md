# Predator_BLA_PL

Code repo for BLA-PL robotic predator experiment analysis.

## Folder structure

**00_prepreprocessing** : Helper function to mark the P and NP events in the video

**01_preprocessing** : Helper function to generate session specific meta-data file. (e.g. # unit, event onset)

**02_Basic_Analysis: Functions to draw descriptive stats (e.g. # of attempts, # of videos per session)

**03_Generate_Classification_Dataset**: Scripts to generate event classification dataset from raw session files

**03a_Classification**: Python scripts to run classification analysis

**04_Communication_btw_PL_BLA**: Scripts for mutual information & transfer entropy

**05_Clustering**: Unsupervised clustering scripts (not used)

**06_Figures**: Scripts for figures
